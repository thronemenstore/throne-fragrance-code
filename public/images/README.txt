Premium-background product photos are included in this folder:
- glory.webp (108 KB) + glory.jpg — GLORY, premium warm off-white background
- midnight-crown.webp (108 KB) + midnight-crown.jpg — MIDNIGHT CROWN
- velora.webp (102 KB) + velora.jpg — VELORA

The storefront serves the .webp versions (about 66% smaller than the JPGs);
if a browser cannot load a .webp, the code falls back to the .jpg of the same name.
To replace a photo, keep the same filename (glory / midnight-crown / velora)
and the same extension — no code change needed.
